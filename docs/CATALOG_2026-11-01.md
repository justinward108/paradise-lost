### Repair

- **Prepare repair parts** (`repair_parts`) · 2 XP required: 3 Metal fasteners, 1 Refined metal, 1 Cloth → 3 Repair parts. 40s base time.

Recipe learning costs one learning voucher. Batch crafting reserves inputs at start and produces output once at completion. Bulk material discounts remain 10% for 5–9, 15% for 10–19 and 20% for 20 batches; each material rounds up.

## Planting and resource acquisition

All new seeds are sold by the visiting seed trader in the starter neighborhood. New produce can also be bartered there for learning vouchers. Harvested crops return planting material. Growth times are prototype watered game days, not real-world growing guidance.

- **Tomato**: 3 watered days, regrows every 2 watered days.
- **Carrot**: 3 watered days.
- **Corn**: 4 watered days.
- **Wheat**: 4 watered days.
- **Sugarcane**: 6 watered days, regrows every 3 watered days.
- **Kitchen herbs**: 2 watered days, regrows every 2 watered days.
- **Coffee shrub**: 7 watered days, regrows every 3 watered days.
- **Cacao tree**: 8 watered days, regrows every 4 watered days.
- **Pineapple**: 6 watered days, regrows every 3 watered days.
- **Cotton**: 5 watered days.
- **Leafy greens**: 2 watered days.
- **Sweet potato**: 5 watered days.
- **Papaya**: 8 watered days, regrows every 3 watered days.
- **Long beans**: 3 watered days, regrows every 2 watered days.
- **Banana**: 10 watered days, regrows every 5 watered days.

### Prospecting

Craft a mining pick. Each job uses one water, occupies the activity slot, and returns two selected resources plus two stone. Three jobs per plot per game day. Collect output through Skills & workshop. This is timed prospecting; underground exploration remains pending.

- **Metal ore**: 0 mining XP, 60 seconds base time.
- **Silica**: 0 mining XP, 60 seconds base time.
- **Clay**: 0 mining XP, 60 seconds base time.
- **Limestone**: 2 mining XP, 60 seconds base time.
- **Unprocessed salt**: 2 mining XP, 60 seconds base time.
- **Coal**: 2 mining XP, 60 seconds base time.
- **Copper ore**: 2 mining XP, 90 seconds base time.
- **Tin ore**: 2 mining XP, 90 seconds base time.
- **Iron ore**: 4 mining XP, 90 seconds base time.
- **Quartz**: 4 mining XP, 90 seconds base time.
- **Uncut gemstones**: 12 mining XP, 180 seconds base time.
